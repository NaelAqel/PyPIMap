PyPIMap Guide

PyPIMap visualizes the PyPI dependency ecosystem. Depends on means packages this one needs; Used by means packages that need this one. Core edges are required; optional edges come from extras. active_version is the PEP 440 active release (prefer final), not last upload time.

Public JSON API: /search, /package/api/{name}, /graph/{name}/depends-on, /graph/{name}/used-by, /last_update. See also /mcp and llms.txt for agents.

Bulk data: Kaggle dataset DOI 10.34740/kaggle/ds/10945692.
