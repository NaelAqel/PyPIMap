PyPIMap MCP

Read-only Model Context Protocol tools over the public PyPIMap API. Interactive package lookup for agents - not a bulk catalog dump.

Hosted MCP: https://mcp.pypimap.com/mcp (streamable HTTP). Docs: pypimap.com/mcp.

Tools: search_packages, package_info, package_depends_on, package_used_by, last_update. Glossary: Depends on / Used by, optional, active_version. importance_score = used_by_core_counts + 0.3 * used_by_optional_counts.

ChatGPT / remote MCP: use https://mcp.pypimap.com/mcp (streamable HTTP). Cursor / Claude Desktop: stdio - see mcp/ in the GitHub repo.

Rate limits (HTTP): 60/min and 2000/day per IP. Bulk offline: Kaggle DOI 10.34740/kaggle/ds/10945692.
