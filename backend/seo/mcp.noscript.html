PyPIMap MCP

MCP is a plug so an AI app can call PyPIMap tools (search, Depends on, Used by) over the public API. Interactive lookup - not a bulk catalog dump.

Start here - pick A or B

A. Hosted URL (streamable HTTP): https://mcp.pypimap.com/mcp - when the product has add remote MCP / server URL (e.g. some ChatGPT plans).

B. Local stdio: install pypimap-mcp from mcp/ on GitHub - Cursor, Claude Desktop (Claude often rejects the hosted URL).

No MCP in the product -> public JSON API at api.pypimap.com/docs. That is the client limit, not MCP down.

Glossary: Depends on = packages this one needs (dependencies, requires). Used by = packages that need this one (dependents, who uses). Core/optional, active_version, importance_score = used_by_core_counts + 0.3 * used_by_optional_counts. parent/child is ambiguous - prefer Depends on / Used by.

Tools: search_packages, package_info, package_depends_on, package_used_by, last_update. Docs: pypimap.com/mcp.

Rate limits (HTTP): 60/min and 2000/day per IP. Bulk offline: Kaggle DOI 10.34740/kaggle/ds/10945692.
