PyPIMap Guide

PyPIMap visualizes the PyPI dependency ecosystem. Depends on means packages this one needs (also: dependencies, requires); Used by means packages that need this one (also: dependents, who uses). Core edges are required; optional edges come from extras. active_version is the PEP 440 active release (prefer final), not last upload time.

Public JSON API: /search, /package/api/{name}, /graph/{name}/depends-on, /graph/{name}/used-by, /last_update. Agents: /mcp (connect A hosted URL or B local stdio) and llms.txt.

Bulk data: Kaggle dataset DOI 10.34740/kaggle/ds/10945692.
